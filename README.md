# 📋 Job Application Tracker

A modern, responsive web application that helps users efficiently track and manage their job applications in one place. Built using **HTML, CSS, and JavaScript**, this project demonstrates strong frontend development skills along with algorithm implementation (Merge Sort).

---

## 🚀 Live Overview

The Job Application Tracker allows users to:

* Create an account and log in securely (client-side)
* Add and manage job applications
* Filter and sort applications dynamically
* View real-time statistics of applications

---

## ✨ Features

### 🔐 Authentication System

* User Registration & Login
* Form validation (password length, matching passwords)
* Session-based user handling

### 📊 Application Management

* Add job applications with:

  * Company Name
  * Position
  * Application Date
  * Status (Applied, Interview, Offer, Rejected, Accepted)
  * Notes
* Delete applications

### 🔍 Filtering & Sorting

* Filter applications by status
* Sort applications using **Merge Sort Algorithm**

  * Date (Newest / Oldest)
  * Company (A–Z / Z–A)
  * Status

### 📈 Dashboard Statistics

* Total Applications
* Applied Count
* Interview Count

### 🎨 UI/UX Design

* Modern gradient UI
* Responsive design (mobile-friendly)
* Smooth animations and transitions

---

## 🧠 Algorithm Used

### Merge Sort

This project uses the **Merge Sort algorithm** to efficiently sort job applications.

**Why Merge Sort?**

* Time Complexity: `O(n log n)`
* Stable sorting algorithm
* Efficient for large datasets
